# 일반조서 관리 2차 설계

2026-09-24 ~ 09-26 사용자와 정한 것. 1차(v3.19.0, 2026-09-15)는 틀 옮기기 엔진과 화면까지 만들었고 실물로는 아직 돌리지 않았다.
조서별 기본값은 같은 폴더의 `일반조서_조서별규칙_초안.xlsx`(사용자 검토 반영본)가 정본이다.

## 1. 원칙

- **시스템은 조서를 대신 쓰지 않는다.** 하는 일은 넷 — 전기 틀을 당기로 옮기고, 날짜·담당자를 적고, 진행 상태를 추적하고, 서술이 필요한 조서에 초안을 대 준다. 판단과 내용은 사람이 쓴다.
- **파일은 고치지 않는다.** 외부감사법 제19조 — 조서 파일은 판이 쌓일 뿐이다(`gwp_book`, 1차 그대로). 매일 바뀌는 상태는 파일과 떼어 표로 둔다.
- **날짜의 정본은 조서목록 시트다.** 화면에서 적은 작성자·작성일을 조서목록 D·E열에 써 넣고, 각 조서 머리는 링크로 따라간다(1차에서 링크는 이미 건다).
- **대화형으로 연다.** 화면이 「지금 할 차례」를 한 줄로 묻고, 사람은 확인하거나 고친다.

## 2. 네 축

| 축 | 값 | 출처 |
|---|---|---|
| 조서 | 조서코드(1100, 2700A-1, 8110ARP …) | 1차 `codeOf` — 「(소규모)」 꼬리를 떼고 하나로 본다 |
| 단계 | 계획 · 중간 · 기말 | 명진 FY25 조서 머리 작성일 — 계획 04-14(1000·2000), 중간 12-26(3100~3400), 기말 03-23(3500~3700·8000) |
| 갱신유형 | ① 그대로 · ② 날짜·담당자 · ③ 새로 작성 · ④ 누적 · 참고 · 첨부 · 시스템 | 규칙 xlsx(사용자 검토) |
| 상태 | 미착수 · 작성중 · 작성완료 · 검토완료 | 사람이 화면에서 |

여러 단계에 걸쳐 다시 쓰는 조서(2700 중요성 — A-1 계획 · A-2 수행 · A-3 완결)는 단계마다 상태 행이 따로 있다. 조서목록에는 마지막 단계의 날짜가 들어간다.

## 3. 조서 양식 기준 — 회계기준과 다른 값이다

- 조서 양식 기준은 **K-IFRS · 일반 · 소규모** 셋. 재무제표 회계기준(DSD)과 다른 값이다 — 조서가 K-IFRS 면 재무제표는 K-IFRS, 일반·소규모면 재무제표는 일반기업회계기준.
- **일반↔소규모는 해마다 바뀔 수 있고 감사계약 때 확정된다.** 그 값은 **일반조서 당기 세팅에서 적는다**(사용자 결정 2026-09-26). 기본값은 전기 기준, 등록 때 확인을 받는다.
- ⚠️ 1차 코드는 조서 기준을 `dsd_engagement.basis`(DSD 회계기준 칸)에 덮어쓴다. 2차에서 떼어 내고, 두 값이 어긋나면(조서 K-IFRS 인데 DSD 일반기업 등) 경고한다. 2026-09-26 현재 소규모로 저장된 건은 0건이다.

## 4. 표

1차의 `gwp_template`(표준양식 묶음) · `gwp_book`(조서 파일 판)은 그대로 둔다. 셋을 더한다.

**`gwp_year` — 일반조서 당기 세팅** (작업 건마다 하나)

| 칸 | 뜻 |
|---|---|
| engagement_id | 작업 건(`dsd_engagement`, 회사 × 사업연도 × 별도/연결) — 유일 |
| audit_basis | 조서 양식 기준 K-IFRS · 일반 · 소규모 |
| basis_confirmed_at / by | 감사계약 확정값으로 확인한 때·사람 |
| partner | 검토자(파트너). 지금은 전 회사 **조현규** |
| author_default | 작성자 기본값. 그 회사 감사 매출계약의 담당회계사(18곳 중 17곳 정우철, 에스씨티 김준성) |
| template_fy | 쓴 표준양식 연도 |
| stage | 지금 단계 — 계획 · 중간 · 기말 · 완료 |

**`gwp_paper_rule` — 조서 규칙(기본값)**

| 칸 | 뜻 |
|---|---|
| basis · code | 기준별 조서 — 유일 |
| name · section | 조서명 · 1000/2000/3000/8000 |
| stages | 작성 단계(여럿일 수 있음) |
| carry | 갱신유형 |
| applies · condition | 항상 · 조건부 · 해당없음 · 조건(초도·상장·연결·통제의존 …) |
| note | ERP 수행 문구, 2120A 링크, 초안 도움 대상 등 |
| check_group | 일관성 점검 묶음(아래 7) |

규칙 xlsx 를 그대로 시드로 넣는다. 회사별 예외는 아래 `gwp_paper` 가 덮는다.

**`gwp_paper` — 회사·연도별 조서 상태** (당기 세팅 × 코드 × 단계)

| 칸 | 뜻 |
|---|---|
| year_id · code · stage | 유일 |
| performed | 수행여부(조서목록 C열 「O」) |
| carry | 이 회사만의 갱신유형(없으면 규칙 값) |
| status | 미착수 · 작성중 · 작성완료 · 검토완료 |
| author · written_on | 작성자 · 작성일(손으로, 타임리포트 근거) |
| reviewer · reviewed_on | 검토자(기본 파트너) · 검토일 |
| note | 메모 |

권한은 1차와 같다 — 감사팀(`is_audit_staff()`: 최고관리자·회계사)만 읽고 쓴다. 새 함수는 PUBLIC 실행권한부터 회수한다(마이그 0150 규칙).

## 5. 한 해의 흐름

1. **양식 등록** — 연초에 한공회 묶음(연도 × 기준)을 올린다(1차 그대로).
2. **당기 세팅(대화형)** — 작업 건을 고르면 차례로 묻는다.
   전기 최종본은 이것을 쓸까요 → 조서 기준은 전기 「소규모」, 올해 감사계약도 소규모인가요 → 검토자 조현규, 작성자 정우철 맞나요 → 이월본 만들기.
3. **이월본** — 같은 기준이면 1차 엔진, 기준이 바뀌었으면 기준 전환 이월(아래 6). 갱신유형대로 조서마다 할 일이 정해진다.
   ① 그대로 · ② 본문의 날짜·담당자 칸을 확인 목록으로 · ③ 전기를 틀로 두고 「당기 작성」 표시 · ④ 전기 내용을 남기고 당기를 덧붙일 자리 표시(특수관계자검토24 → 25 처럼 시트를 새로).
4. **계획 → 중간 → 기말** — 단계 화면은 그 단계에 남은 조서만 보여 준다. 조서 여러 개를 골라 **날짜 하나를 한 번에** 찍는다. 저장하면 조서목록에 써 넣은 새 판이 쌓인다. 다 닫히면 다음 단계가 열린다.
5. **최종본** — 감사 종료 뒤 판 하나를 최종본으로 표시한다.
6. **Audit Lobby 분할** — 최종본을 섹션 묶음으로 쪼개 내려받는다(명진 FY2024·2025 실물과 같은 이름):
   `1000_감사계약(1000~1200).xlsx` · `2000_위험평가(2000~2700).xlsx` · `3000_위험대응(3000~3700).xlsx` · `8000_감사종결(8100~8700).xlsx` · `8900_아카이브 체크리스트_회사명.xlsx`. 별도 파일(감사전략계획서 docx, 8400 공시사항점검표 등)은 목록으로 짚어 준다.

## 6. 기준 전환 이월

1차 엔진은 전환을 모른다(같은 코드면 갈아끼우고, 숨김 시트는 그대로). 전환 때는:

- **일반 → 소규모**: 소규모에 없는 조서(2512·2513 등)는 **숨긴다** — 지우지 않는다. 명진이 두 벌을 숨김/보임으로 남긴 관행 그대로.
- **소규모 → 일반**: 일반에만 있는 조서를 양식에서 새로 이식한다.
- **양쪽에 다 있는 조서**: 당기 기준 쪽 시트를 보이게 하고, 전기 보이던 쪽의 값을 라벨 짝짓기로 옮긴다. 양식이 달라 못 옮기는 칸이 많아지니 결과표에서 크게 보여 준다. 시트 이름의 「(소규모)」 꼬리도 당기 기준을 따른다.
- **K-IFRS ↔ 일반·소규모**: 드물다. 경고하고 「양식으로 새로 만들기」를 권한다.

## 7. 일관성 점검 — 위험평가와 대응은 서로 맞아야 한다

비상장 기본 세팅(사용자 안내 2026-09-26): 2302 유의적 위험 = **부정위험 · 매출(수익인식)** · 2530/3150 **통제테스트 안 함**(이해·평가만) · 3100 **실증절차 위주, 통제위험에 대응해 기말 테스트 범위 확대**. 회사 특화 문구만 손본다.

- 1단계: 계획단계에서 「기본 세팅 그대로인가요」를 묻고, 벗어나면 이유를 메모로 받는다(2301·2302·2530·3100·3150 을 한 묶음으로).
- 2단계(나중): 조서 칸을 직접 읽어 선택이 어긋나면 경고한다. 칸 위치가 양식 연도마다 달라 규칙을 조서별로 잡아야 한다.

## 8. 내용 작성 도움

대상은 회사 사업 이해(2100 · 2100A)와 내부통제·IT(2511~2513 · 2520 · 2531 · 2532 · 2600) — 비상장이라 채우기 어려운 자리. 전기 조서 내용과 거래처관리의 회사 정보를 근거로 초안을 낸다. 개인정보는 `pii.ts` 로 가려서 보낸다. 처음에는 **복사할 초안 문장**을 보여 주고, 칸에 써 넣기는 나중에 한다.

## 9. 고정 문구

- 1100 · 1100A · 1200 은 **인덕 ERP 에서 평가를 마친다** — 조서 본문엔 「ERP 에서 수행함」.
- 8100A 왜곡표시 집계표는 기본 결론 「해당사항 없음」을 적고 그대로 이어 간다. 기말단계에 「올해도 왜곡표시가 없나요」를 묻고, 있는 해만 새로 쓴다(사용자 안내 2026-09-26 — 알티스트는 두 해 동안 고치지 않고 넘어간 실물).
- 2120 은 2120A 를 링크로 건다. 8550 심리사항점검표는 심리실 소관이라 해당없음. 2600 내부회계는 상장회사만. 1300C 는 K-IFRS 만.

## 10. 만드는 순서

1. **기준 분리 + 당기 세팅** — `gwp_year`, DSD 회계기준 칸에서 떼기, 대화형 세팅(기준·파트너·작성자).
2. **조서 규칙** — `gwp_paper_rule` + 규칙 xlsx 시드.
3. **조서 상태와 단계 화면** — `gwp_paper`, 계획/중간/기말 화면, 날짜 일괄 기입, 조서목록 써 넣기.
4. **기준 전환 이월**.
5. **최종본 + Audit Lobby 분할**.
6. **일관성 점검 1단계 + 초안 도움**.

1~3 이 되면 명진(소규모)으로 FY2026 을 실제로 한 바퀴 돌려 본다.

## 11. 샘플 실측으로 바뀐 것(2026-09-26)

샘플: 명진(소규모 FY25) · 알티스트(일반 FY24·FY25, 같은 기준 유지) · 윤성에프앤씨(K-IFRS·지정 FY25). 기준이 바뀐 회사 샘플은 없다.
근거는 규칙 xlsx 의 「일반 실측(알티스트)」「K-IFRS 구성(윤성)」「기준별 번호 차이」 시트.

- **번호가 곧 조서가 아니다.** 같은 번호가 기준·양식 판마다 다른 조서다 — 1200(소규모=독립성, 일반·K-IFRS=업무조건 합의),
  2700A-1~4(알티스트만 한 칸 밀림), 8600(윤성=감사종료, 나머지=의견형성). 조서 규칙의 열쇠는 **기준 × 양식 연도 × 코드**,
  이월·기준 전환의 짝짓기는 **시트 제목(조서명)** 으로 한다.
- **파일 형태가 둘이다.** 워크북 하나(명진·알티스트)와 섹션 분할 4파일(윤성). 섹션 파일마다 표지·조서목록·기본사항이
  반복되고, 중요성(2700 계열)은 2000·3000·8000 파일에 단계마다 다시 들어 있다. 받기·내보내기 모두 두 형태를 다룬다.
- **조서목록 모양이 회사마다 다르다.** 시트 이름(조서목록 / 감사조서목록), 열 위치(명진 B·C·D·E / 알티스트·윤성 B·C·D·F·H),
  위쪽 영구조서 구역, 수행여부 값(O · 계약시 · ERP · N/A), K-IFRS 의 반기검토 열. 열은 위치가 아니라 머리글로 찾는다.
- **1년 사이 대부분 그대로다.** 알티스트 코드 조서 59개 중 44개가 FY24→FY25 본문(머리 1~8행 제외)이 거의 그대로였다.
  바뀐 것은 **숫자 시트(A 붙은 것 — 2120A·2700A-x·8110A, 1100 보수·시간)** 와 **서술·특수관계자(2100A·3500A·3500B·회사 특수관계자 시트)**.
  본문에 날짜가 거의 없어 「② 날짜·담당자」는 드물다(2110·2110-1·3700 정도). → 원칙: **결론 시트는 그대로, 숫자 시트는 새로, 사업이해·특수관계자는 누적.**
- **머리 날짜가 어긋난 실물이 흔하다.** 알티스트 조서목록은 04-28 인데 2500 대 머리는 10-12, 8110A 머리는 전년 날짜 그대로,
  윤성 8600 머리 2022·3900D 결산일 2021. → 조서목록 한 곳에서 날짜를 내려보내는 것이 이 시스템의 핵심 가치다.
- **단계 날짜가 회사마다 다르다.** 알티스트는 2500·2600·3100·3400 이 10월(중간), 명진은 2500 이 4월(계획). 규칙은 기본 단계만 주고 회사별로 고친다.
- **K-IFRS·지정감사(윤성)는 예외가 많다.** 통제테스트를 실제로 한다(2530A·B 시트), 1000번대 작성자가 파트너(조현규), 반기검토 조서화 열이 있다.
  비상장 기본 세팅(7절)은 K-IFRS·지정에는 기본값으로 쓰지 않는다.

## 12. 이월 원칙 — 전기 시트를 그대로 잇는다(사용자 결정 2026-09-27)

명진 FY25 를 1차 엔진(양식이 98% 미만 같으면 갈아끼움)으로 이월했더니 32개를 갈아끼우고 2120A 702칸·2520 103칸 등 작년 내용이 빠졌다.
명진이 일반용 시트와 옛 양식을 섞어 써 2026 소규모 양식과 글자가 거의 안 맞았기 때문이다(2301·2520 일치 0%).
사용자 결정: **「전기 시트를 그대로 잇는 것을 기본으로. 대부분의 시트는 양식이 많이 바뀌지 않습니다.」**

- 기본 = 전기 시트 그대로. 머리만 당기로(표지·조서목록 링크, 검토자 = 파트너). 하위 조서는 윗 조서 조서목록 줄을 따른다(2100A→2100, 2302→2301, 8110→8100).
- 양식과 다른 조서 = 「그대로」 + 「올해 양식과 n% 같음」 표시. **갈아끼우기는 사람이 골라서만.**
- 양식에만 있는 조서 = 「양식에만 있음」으로 알리기만. **넣기는 사람이 골라서만.** (8400 별도 파일·8550 심리실·3150 통제테스트·2026 양식의 번호 밀린 중요성 시트가 저절로 들어오던 것을 막는다)
- 고른 것을 반영해 다시 만들면 새 판이 하나 더 쌓인다(판은 지우지 않는다).

## 13. 탭 색·노란 칸·날짜 올리기·전기 이동(사용자 2026-09-27, v3.23.0)

- **탭 색 = 진행 상태** (사무소 관행): 빨강 = 올해 아직 손 안 댐 · 노랑 = 수정함 · 초록 = 수정했지만 새로 넣을 내용이 없음. 이월본은 보이는 조서·표지·조서목록·회사가 더한 시트 탭을 모두 빨강으로 둔다(새 조서도 빨강). 참고 시트(참고_…·감사조서철 작성 및 보존)는 손대지 않는다. 조서 목록·상태 표는 올린 파일의 탭 색으로 상태를 보인다 — 탭 색이 없는 옛 파일만 머리 값으로 짐작한다.
- **바뀐 칸은 노란 바탕**: 시스템이 올린 날짜, 옮긴 숫자, 비운 당기 칸, 표지 결산일·대상기간·감사보고서일, 조서목록 작성일. 머리 링크(회사명·결산일·작성자·일자·검토자)는 모든 조서에 같게 걸리니 칠하지 않는다.
- **날짜 올리기**: 전기 결산일·개시일과 그 한 해 앞(날짜 칸의 일련번호, 글자 속 「2025년 12월 31일」 「2025.12.31」), 「제N기」(전기·전전기 기수), 「FY2025/FY25」, 「2024_4Q」(전기 기준 세 해치), 「2025년 말·도·결산·감사」 「2025 사업연도」. 기간의 끝·처음과 월·일이 다른 날짜(설립일·계약일·작성일)와 수식 칸은 둔다.
- **전기 이동**: 2120A·8110A·8110ARP_BS·8110ARP_PL(규칙 표가 생기면 거기서 온다). 머리 줄(40행 안)에서 한 해 차이 나는 두 기간 열을 찾는다 — 글자(「BS: 2023_4Q」) 또는 월·일이 같은 날짜 두 칸(8110ARP 「2025-12-31 │ 2024-12-31」, 당기가 왼쪽일 수 있다). 당기 숫자 → 전기, 당기는 비움. 작년 당기가 비어 있던 줄은 전기도 비움. 당기가 외부 링크 수식이면 계산값만 전기로 적고 수식은 둔다. 둘 다 링크(8110ARP_PL)면 옮기지 않고 「링크를 새 해 파일로」라고 알린다. 머리 연도 글자도 올린다(수식 머리는 두고).
- **「올해 양식이 얼마나 다른가」는 문구로**: 자리 대조는 줄 하나만 밀려도 0%(명진 8100A 320/320). 올해 양식 문구가 작년 시트 **어디에도** 없는 수를 센다. 작년 조서는 문구 안에 답을 적으니(「[V] 예」) 한쪽이 다른 쪽을 품거나 글자쌍 85% 넘게 같으면 같은 문구. 2% 넘게 없으면 「다름」, 문구는 있는데 자리만 다르면 「자리만 다름」. 다른 문구 앞 30개를 올해·작년 나란히 보이고, **올해 양식 참고 파일**(다른 조서만, 다른 문구 노란 바탕)을 내려받는다 — 판으로 올리지 않는다.
- 명진 FY25→FY26 실측: 2120A 48줄 전기 이동·미수수익 줄 비움·B3 2026-12-31, 8110ARP_BS 35줄, 탭 빨강 48, 노란 칸 약 200, 문구 다른 조서 30(8100A 315/320 — 2026 양식에서 번호 내용 자체가 바뀜, 3600 20/40, 1100·2100 은 자리만 다름).
- 다음: 한공회 개정사항총괄(2026_감사조서서식(예시)개정사항총괄)의 조서별 개정여부·개정내용을 「다른 문구」 옆에 붙이면 공식 개정인지 회사 손질인지 가를 수 있다.
